# 战争进化史 · 远征篇

独立浏览器单线策略游戏。打开 `index.html` 即可运行，无需安装依赖。

包含五个时代、十五种兵种、训练队列、基地防御升级、维修、定点战术技能、三档难度、倍速与音效。远征篇新增五关分支战役、军团专长、中央补给站、单局科研、战场号令、精英援军和统帅决战；经典自由战仍可随时进入。

## 远征路线

火种边境 → 王国十字路 / 炮火围城（任选一关）→ 钢铁防线 → 终焉堡垒。通关后可以返回挑战另一条支线，或重打已完成的关卡争取更高勋章。

| 关卡 | 起始时代 | 主要目标 | 速通勋章时限 |
| --- | --- | --- | --- |
| 火种边境 | 石器 | 摧毁敌方营地 | 200 秒 |
| 王国十字路 | 中世纪 | 累计控制中央哨站 60 秒 | 180 秒 |
| 炮火围城 | 火药 | 突破精英炮车增援，摧毁重装要塞 | 300 秒 |
| 钢铁防线 | 工业 | 守住基地 180 秒 | 200 秒 |
| 终焉堡垒 | 未来 | 击败敌方统帅，并摧毁基地 | 300 秒 |

王国十字路必须累计控制哨站 60 秒，钢铁防线必须守住 180 秒；这两关提前摧毁敌方基地仍需完成对应目标。每关最多三枚勋章：通关一枚、结算时基地生命至少 50% 一枚、达到速通时限一枚。保留历次最高勋章、最快通关时间和胜利次数，经典自由战不计入远征进度。

军队自动争夺战场中央的补给站。双方同时在附近时占领进度暂停；我方持有时额外获得金币 +1.5/秒、经验 +0.5/秒，敌方持有时增援更快。远征中的定时援军会出现精英单位，终章还有统帅，需结合前排、远程和重装调整兵力。

## 军团与战术

出征前可选择一项专长，整场战斗生效：

| 专长 | 优势 | 代价 |
| --- | --- | --- |
| 突击军团 | 部队伤害 +12% | 部队生命 −8% |
| 战争工业 | 金币收入 +1/秒 | 训练耗时 +10% |
| 钢铁守卫 | 部队与基地生命 +15% | 部队移速 −10% |

战斗中可花金币研究武器锻造（每级部队伤害 +15%）、装甲强化（每级部队生命 +20%）、补给体系（每级金币收入 +1/秒），各三级。武器和装甲立即影响在场部队，并应用于后续招募；科研只在当前战斗中保留，新战斗重新开始。

战争鼓舞使全军攻速 +35%、移速 +20%，持续 10 秒、冷却 35 秒；战地治疗为每个存活友军恢复其最大生命的 25%，冷却 40 秒。治疗不维修基地；没有受伤友军时不会消耗冷却。

## 操作

- 点击兵种卡征募，或使用 1 / 2 / 3。
- E 进化；Q 选择技能后点击战场确定落点。
- T 升级炮塔；R 维修；空格暂停；Esc 取消选点。
- F 战争鼓舞；H 战地治疗；点击科研按钮进行研究。
- 主菜单选择关卡、军团专长与难度，也可继续本地战斗。

## 本地存档

战斗快照与远征进度分别保存在当前浏览器。战斗存档包含军队、训练队列、随机数状态、关卡目标、补给站、科研、援军、统帅及技能冷却，恢复后继续原战局。远征进度保存解锁、最高勋章、最快时间与胜利次数，并通过战斗 ID 避免刷新结算页重复计数。

旧版 v2 战斗存档自动迁移为经典自由战，保留原有战局与均衡属性；新增科研及号令使用初始状态。新战斗使用 v3 格式。无法读取或损坏的存档会安全回退，不阻止开始新游戏。存档不跨浏览器或设备同步，请使用同一浏览器和页面入口续玩。

## 开发

- `engine.js`：固定步长模拟、AI、规则与存档。
- `campaign.js`：战役解锁、勋章、最快时间与结算去重，无浏览器或存储依赖。
- `renderer.js`：战场、角色、基地、动画与粒子。
- `game.js`：界面与交互。
- `audio.js`：本地合成音效。
- `styles.css`、`expedition.css`：桌面及移动端界面、远征地图与战场策略面板。
- `assets/units/`、`assets/bases/`：真实透明 PNG 美术。

在项目目录启动本地预览：`python3 -m http.server 4173`，然后访问 `http://127.0.0.1:4173/`。

使用 Node.js 22 运行规则验证：

```sh
node tests/engine.test.cjs
node tests/campaign.test.cjs
```

引擎测试覆盖经典战斗、远征目标、专长、科研、号令、旧存档迁移、恢复一致性及多个种子的通关模拟；战役测试覆盖分支解锁、评分、纪录、防重复结算和损坏档案。它们不替代浏览器中的画面、触屏及音效验收。

推送 `main` 或手动触发 GitHub Actions 时，Pages 工作流先运行两套测试，通过后发布静态站点；部署过程无需安装项目依赖或打包。

素材采用获准的 `gpt-image-2` 流式生成；提示词与切图清单保存在 `assets/`。人物使用单幅透明精灵，通过位移、倾斜、受击闪烁和特效呈现动作，并非逐帧骨骼动画。此项目为独立重制，不代表原作或 4399 官方产品。
